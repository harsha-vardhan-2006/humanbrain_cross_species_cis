# Graphical Abstract — description (for the designer/typesetter)

**Title strip:** "Architecture replicates. Anatomy does not."

**Left panel — Human (region scale).** A schematic 456-node cortical/
subcortical graph with one node highlighted in removal position; caption:
"CIS(i) = (E(G) − E(G−i))/E(G), exact, per subject (N = 801)". Below: a
mini-histogram of per-subject top-50 concentration z vs degree-preserving
nulls, all mass right of 0, annotation "200/200 subjects, median z = 16.36".

**Middle panel — the two-layer architecture.** A horizontal bar decomposing
CIS into "degree component (ρ ≈ 0.94)" (long bar) and "degree-independent
residual (δ = 0.100)" (short bar), with a vertical error-style bracket noting
"present in 778/801 subjects".

**Right panel — Fly (cell scale).** A schematic fly brain with the visual
lobe highlighted, caption "80% of top-50 residual = visual-centrifugal";
paired with the human brain showing diffuse subcortical/cerebellar shading,
caption "2% visual; subcortical signal degree-anchored".

**Bottom strip:** two effect-size dots on one axis (δ 0.0979 fly; δ 0.100
human) joined by a bracket labelled "same architecture"; a crossed-out link
between the two anatomies labelled "different anatomy — no homology claim".

**Colors:** neutral gray for degree components; one accent color for the
residual; no funnel/truncated axes; all axes start at 0 or are explicitly
z-scores.
