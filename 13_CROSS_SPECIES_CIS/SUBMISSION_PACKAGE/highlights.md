# Highlights

- Exact per-node control-impact analysis in 801 human structural connectomes (456 nodes each, 900 acquired).
- Top-50 control-impact concentration exceeds degree-preserving null expectations in 200/200 subjects (median z = 16.36).
- CIS is strongly degree-dominated (ρ = 0.94) with a small degree-independent residual in 778/801 subjects (δ = 0.100).
- 43/456 nodes survive BH-FDR; the residual is not robustly system-specific (pre-registered enrichment gate negative).
- Cross-scale comparison with the fly connectome: architecture replicates (δ ≈ 0.10 both scales); anatomical identity of the residual diverges.
- Fully reproducible: frozen pipeline, verified nulls, and a 42-check independent numeric audit shipped with the repository.
