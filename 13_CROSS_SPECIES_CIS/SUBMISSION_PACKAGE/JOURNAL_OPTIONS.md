## Submission-strategy notes (factual, not ranking)
- This paper's strongest policy alignment (public data, frozen code, audit
  culture) is with venues that **require or strongly encourage data/code
  availability** — all listed candidates do to varying degrees.
- The manuscript is long (full discussion + supplementary); venues without
  hard word limits (Network Neuroscience, eLife, HBM style) minimize
  restructuring.
- If APC is a constraint: eLife/Network Neuroscience/Imaging Neuroscience
  have waiver mechanisms; PLOS has institutional partnerships; hybrid venues
  allow subscription publication (no fee) — check each journal's current
  waiver page.
- Preprint posting (bioRxiv) before submission is compatible with all
  candidates and is recommended by several; the Kudriavtsev full-text read
  must precede any public posting (novelty gate closure).
